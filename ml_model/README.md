This folder contains the machine learning model implementation for the 
Autonomous ML Model Monitoring & Drift Management Platform.

## Contents
- Model training notebook
- Data preprocessing steps
- Drift detection logic

## Technologies Used
- Python
- Scikit-learn
- Pandas

## Description
The model is trained to monitor incoming data distributions and detect drift using statistical techniques. It supports automated retraining workflows.
